# Marcello L. Raso — portfolio site

Static site, deployed on Netlify from this repository.

- `index.html` — the whole page
- `img/` — stills, posters, laurels, portrait, social preview (`og.jpg`)
- Contact form uses Netlify Forms (form name: `contact`). Set the notification email to kharmamovie@gmail.com in Netlify → Forms → Form notifications.
- Replace `SITE_DOMAIN` in `index.html`, `robots.txt` and `sitemap.xml` once the domain is live.
