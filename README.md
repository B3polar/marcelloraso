# Marcello L. Raso — portfolio site

Static site, deployed on Netlify from this repository.

- `index.html` — the whole page
- `img/` — stills, posters, laurels, portrait, social preview (`og.jpg`)
- Contact form posts to FormSubmit (formsubmit.co) and delivers to hello@rasostudios.com. The first submission triggers a one-time activation email to that inbox. Works on any static host (GitHub Pages, Netlify, Cloudflare Pages).
- Custom domain: rasostudios.com (see `CNAME`). DNS at Aruba: four A records to GitHub Pages, `www` CNAME to b3polar.github.io.
